## Шпаргалка по командам

```
git status                  что сейчас происходит
git add .                   положить всё в индекс
git add homework.py         положить один файл
git commit -m "сообщение"   создать точку сохранения
git log --oneline --graph   посмотреть историю
git diff                    что я изменил с последнего коммита
git switch -c lesson-04     создать ветку и перейти в неё
git switch main             вернуться в main
git push                    отправить на GitHub
```

Не помнишь, что происходит — набирай `git status`.
Он почти всегда сам подсказывает следующую команду.

## Как сдать

С этого занятия работы принимаются **только через git**:

```
git add .
git commit -m "lesson 03: задания по выписке"
git push
```

Файлы в мессенджере больше не считаются сданными — это часть профессиональной привычки.

## Если push просит логин и пароль

GitHub давно не пускает по обычному паролю. Нужен либо personal access token,
либо вход через GitHub CLI. Разберём на занятии — если не получилось дома,
не сиди над этим час, напиши.
